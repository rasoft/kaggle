# Agent Builder

智能体构建器 (Agent Builder)

**Vertex AI Agent Builder** is a collection of products and services for developers. We have put together a comprehensive platform for you to build and connect agents. The engineering excellence and security from Google Cloud, the AI research from Google Deepmind, and the best practices of AgentOps. Google Cloud is building our own agents on top of this platform, and now you can too. Expect many more exciting announcements 2025 targeting developers of agents.

**Vertex AI Agent Builder** 是面向开发者的一组产品与服务。我们搭好了一套完整平台，供你构建并连接智能体 (Agent)。它汇集了 Google Cloud 的工程水准与安全性、Google Deepmind 的 AI 研究，以及智能体运维 (AgentOps) 的最佳实践。Google Cloud 正在这个平台上构建我们自己的智能体，现在你也可以。可以期待 2025 年还有更多面向智能体开发者的精彩发布。

**Vertex AI Agent Engine** streamlines development, relying on Google engineering managed integrations with popular open source agent libraries. It provides a managed autoscaling runtime and many services agents will need (eg: session, examples, trace, evals). This is the very low effort and high value way to safely deploy agents you have written in any framework.

**Vertex AI Agent Engine** 简化开发，依靠由 Google 工程团队托管的、与流行开源智能体库的集成。它提供托管的自动扩缩运行时，以及智能体需要的许多服务（例如：会话、示例、追踪、评估 (Evaluation)）。这是一种低投入、高价值的方式，可以安全地部署你用任何框架写好的智能体。

**Vertex AI Eval Service** provides all of the evaluation tools discussed in this whitepaper, and more. LLMs, RAG, and Agent evals are stable and scalable via the Vertex AI Eval Service, with convenient integrations into monitoring and experimentation offerings.

**Vertex AI Eval Service** 提供本白皮书讨论过的全部评估工具，并且还有更多。大语言模型 (LLM)、检索增强生成 (RAG) 和智能体评估，都经由 Vertex AI Eval Service 保持稳定、可扩展，并能方便地接入监控与实验类产品。

A large portfolio of agent tools, with more to watch out for:

智能体工具 (Tools) 的组合已经很大，后续还有更多值得关注：

- Retrieval via Vertex AI Search<sup>26</sup> or RAG Engine<sup>28</sup>.

- 经由 Vertex AI Search<sup>26</sup> 或 RAG Engine<sup>28</sup> 进行检索。

- Non-search based retrieval from DBs via Gen AI Toolbox for Databases<sup>32</sup>

- 经由 Gen AI Toolbox for Databases<sup>32</sup>，从数据库做非搜索式检索

- Application integrations<sup>33</sup> with hundreds of APIs supporting full ACLs

- 应用集成<sup>33</sup>，覆盖数百个支持完整访问控制列表 (ACL) 的 API

- Turn any API into a managed, enterprise ready tool with Apigee Hub<sup>34</sup>

- 用 Apigee Hub<sup>34</sup> 把任意 API 变成托管的、企业可用的工具

And of course the best LLMs for agents, with access to Vertex AI Model Garden<sup>35</sup> and also the Gemini family of models<sup>36</sup> which will power the agentic era.

当然，还有最适合智能体的大语言模型：可以访问 Vertex AI Model Garden<sup>35</sup>，也可以使用将推动智能体时代的 Gemini 模型家族<sup>36</sup>。
