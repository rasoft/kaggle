## What is the 5-Day of AI Agents: Intensive Vibe Coding Course?

<mark>什么是「5 日 AI 智能体：高强度氛围编码课程」？</mark>

The [5-Day AI Agents: Intensive Vibe Coding Course With Google](https://www.kaggle.com/competitions/5-day-ai-agents-intensive-vibecoding-course-with-google) is a hands-on program originally held live from June 15 - 19, 2026. It is now available as a self-paced Kaggle Learn guide so anyone can explore the foundations, architecture and practical development of AI agents.

<mark>[与 Google 一起的 5 日 AI 智能体：高强度氛围编码课程](https://www.kaggle.com/competitions/5-day-ai-agents-intensive-vibecoding-course-with-google)是一门动手实践课程，最初于 2026 年 6 月 15 日至 19 日以直播形式举办。它现在作为自定进度的 Kaggle Learn 指南开放，任何人都可以借此探索 AI 智能体 (Agent) 的基础、架构与实际开发。</mark>

This course was crafted by Google's ML researchers and engineers to help developers dive deeper into building powerful AI agents from foundational concepts to production-ready systems. You'll explore vibe coding workflows, where natural language becomes the primary programming interface, and learn how to create "10x agents" by integrating tools, APIs, and multi-agent systems. Along the way, you'll build skilled agents with memory and context, evaluate quality and security, and take your projects from prototype to scalable, observable deployments.

<mark>这门课程由 Google 的机器学习 (ML) 研究人员和工程师设计，帮助开发者从基础概念一路深入，直到构建可投入生产的强大 AI 智能体系统。你将探索氛围编码 (Vibe Coding) 工作流：在这种工作流里，自然语言成为主要的编程界面。你还将学习如何通过整合工具 (Tools)、API 和多智能体系统，打造「10 倍智能体 (10x agents)」。沿途你会构建具备技能、记忆 (Memory) 和上下文的智能体，评估质量与安全，并把项目从原型带到可扩展、可观测的部署。</mark>

Each day combines conceptual deep dives with hands-on examples and practical guidance. By the end, you'll be ready to design, build, and deploy robust agent systems, culminating in a capstone project that brings your ideas to life.

<mark>每一天都把概念深入讲解、动手示例和实践指导结合在一起。课程结束时，你将能够设计、构建并部署稳健的智能体系统，并以一个把想法变成现实的综合实践项目 (capstone project) 收尾。</mark>

## Day 1 (Introduction to Agents & Vibe Coding)

<mark>第 1 天（智能体与氛围编码入门）</mark>

Welcome to Day 1.

<mark>欢迎来到第 1 天。</mark>

This whitepaper talks about the transition from manual syntax coding to intent-driven "vibe coding" and disciplined "agentic engineering." It explores how AI agents compress the traditional software development life cycle (SDLC) and explains the "factory model" where developers act as system orchestrators who design the evaluation, constraint, and context harnesses that safely guide autonomous execution.

<mark>这篇白皮书讨论从手工按语法写代码，转向意图驱动的「氛围编码」，以及有纪律的「智能体工程 (Agentic Engineering)」。它探讨 AI 智能体如何压缩传统的软件开发生命周期 (SDLC)，并解释「工厂模型 (Factory Model)」：开发者充当系统编排者 (Orchestrator)，设计评估、约束和上下文的驾驭层 (Harness)，从而安全地引导自主执行。</mark>

In the codelabs, you'll familiarize yourself with Antigravity 2.0, the Antigravity IDE, and the Antigravity CLI to vibecode your first applications. You'll also use Google AI Studio to deploy your app to Cloud Run, enabling you to share your vibe coded app with your friends.

<mark>在代码实验 (codelab) 里，你将熟悉 Antigravity 2.0、Antigravity IDE 和 Antigravity CLI，并用氛围编码写出你的第一批应用。你还会用 Google AI Studio 把应用部署到 Cloud Run，从而把氛围编码做出来的应用分享给朋友。</mark>

## Day 2 (Agent Tools & Interoperability)

<mark>第 2 天（智能体工具与互操作性）</mark>

Welcome to Day 2.

<mark>欢迎来到第 2 天。</mark>

This whitepaper talks about standardizing the plug-and-play AI ecosystem using open protocols to eliminate the complex technical debt of custom tool integrations. It details how the Model Context Protocol (MCP) connects models to data sources, outlines Agent2Agent (A2A) collaboration, showcases Agent-to-User Interface (A2UI) for generative UI, and introduces Agent Payments Protocol (AP2) and Universal Commerce Protocol (UCP) for secure machine-to-machine commerce.

<mark>这篇白皮书讨论用开放协议把即插即用的 AI 生态标准化，从而消除定制工具集成带来的复杂技术债。它说明模型上下文协议 (Model Context Protocol, MCP) 如何把模型 (Model) 接到数据源，概述智能体对智能体 (Agent2Agent, A2A) 协作，展示用于生成式界面 (Generative UI) 的智能体到界面 (Agent-to-User Interface, A2UI)，并介绍用于安全的机器对机器商务的智能体支付协议 (Agent Payments Protocol, AP2) 和通用商务协议 (Universal Commerce Protocol, UCP)。</mark>

In today's codelabs, you'll learn how to add MCP servers to Antigravity, giving it access to the canonical, machine-readable source of Google's public developer documentation. You'll then extend your familiarity with Antigravity by using it via the terminal with Antigravity CLI.

<mark>在今天的代码实验里，你将学习如何把 MCP 服务器加到 Antigravity，让它能够访问 Google 公开开发者文档的权威、机器可读来源。接着，你将通过在终端里使用 Antigravity CLI，进一步熟悉 Antigravity。</mark>

## Day 3 (Agent Skills)

<mark>第 3 天（智能体技能）</mark>

Welcome to Day 3.

<mark>欢迎来到第 3 天。</mark>

This whitepaper talks about managing dynamic context and avoiding "context rot" by equipping agents with portable "Agent Skills", directories structured around a central SKILL.md file. It explains how this framework uses progressive disclosure to keep system prompts lightweight, loading execution details and tools only on demand so that single agents can flex into hundreds of specialist roles efficiently.

<mark>这篇白皮书讨论如何管理动态上下文，并通过给智能体配备可移植的「智能体技能」来避免「上下文腐烂 (Context Rot)」。这些技能是围绕核心 `SKILL.md` 文件组织起来的目录。它说明这套框架如何用渐进式披露 (Progressive Disclosure) 让系统提示保持轻量，只在需要时才加载执行细节和工具，使单个智能体能够高效地灵活切换成数百种专家角色。</mark>

In the codelabs, you will familiarize yourself with skills in Antigravity. Then, using Antigravity, you will install and use Agents CLI skills to create agents, lint your code, and test your agent, all by using natural language prompts.

<mark>在代码实验里，你将熟悉 Antigravity 中的技能。然后，你将借助 Antigravity，安装并使用 Agents CLI 的技能来创建智能体、检查代码 (lint) 并测试智能体，全程使用自然语言提示。</mark>

## Day 4 (Vibe Coding Agent Security and Evaluation)

<mark>第 4 天（氛围编码智能体的安全与评估）</mark>

Welcome to Day 4.

<mark>欢迎来到第 4 天。</mark>

This whitepaper talks about redefining security and evaluation in non-deterministic AI workflows by establishing continuous "Effective Trust" through a strict 7-pillar architecture. It outlines practical safeguards such as ephemeral sandboxing, defenses against hallucinated "slopsquatting" packages, an active Red/Blue/Green security triad, and OpenTelemetry trajectory evaluation.

<mark>这篇白皮书讨论如何在非确定性的 AI 工作流里重新定义安全与评估：通过严格的 7 支柱架构，建立持续的「有效信任 (Effective Trust)」。它列出了实际的防护措施，包括临时沙箱 (ephemeral sandboxing)、针对幻觉出来的「包名抢注 (slopsquatting)」软件包的防御、主动的红队 / 蓝队 / 绿队安全三角 (Red/Blue/Green security triad)，以及 OpenTelemetry 轨迹评估。</mark>

In the codelabs, you will create an agent with human-in-the-loop so that humans can manually intervene, using ADK, Agents CLI and Antigravity. You will also learn about how to develop a secure, test-driven development with Antigravity.

<mark>在代码实验里，你将使用 ADK、Agents CLI 和 Antigravity，创建一个带人在回路 (Human-in-the-Loop, HITL) 的智能体，以便人工介入。你还将了解如何用 Antigravity 开展安全的测试驱动开发 (test-driven development)。</mark>

Welcome to Day 5.

This whitepaper covers bridging the gap between fragile vibe-coded prototypes and production-grade enterprise software using Spec-Driven Development (SDD). It details how to treat code as disposable and behavior-driven Gherkin specifications as the source of truth, establishing safe, zero-trust development pipelines with automated code-review agents and hybrid Policy Servers.

<mark>这篇白皮书讨论如何用规格驱动开发 (Spec-Driven Development, SDD)，弥合脆弱的氛围编码原型与生产级企业软件之间的差距。它说明怎样把代码视为可丢弃的，把行为驱动的 Gherkin 规格视为唯一事实来源，并借助自动化代码评审智能体和混合策略服务器 (hybrid Policy Server)，建立安全的零信任 (zero-trust) 开发流水线。</mark>

In the codelabs, you will learn how to create and deploy an agent to Google Cloud for enterprise scale. Then you will use Antigravity to vibe code a frontend client interface deployed to Cloud Run and tie it to an asynchronous event-triggering architecture that automatically feeds live expense submissions straight to your cloud-hosted agent. While these codelabs are optional today because they may require a billing account on Google Cloud, we still encourage you to scan through them to familiarize yourself with what productionization of agents and apps might look like at enterprise scale.

<mark>在代码实验里，你将学习如何创建智能体并部署到 Google Cloud，以达到企业级规模。然后，你将用 Antigravity 以氛围编码做出部署在 Cloud Run 上的前端客户端界面，并把它接到一套异步事件触发架构上。这套架构会把实时的费用提交自动送进你托管在云端的智能体。这些代码实验今天标为可选，因为它们可能需要 Google Cloud 结算账号。我们仍建议你浏览一遍，了解智能体和应用在企业级规模上的生产化大概是什么样子。</mark>
